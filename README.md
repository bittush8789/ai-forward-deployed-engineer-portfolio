## 🛠️ Local Development & Quickstart

Because this project uses vanilla web standards, **no build step, npm install, or bundler is required**.

### Option 1: Python HTTP Server (Recommended)
```bash
# Clone or navigate to the repository
cd New-portfolio

# Start a lightweight local server on port 8080
python -m http.server 8080
```
Open [http://localhost:8080](http://localhost:8080) in your browser.

### Option 2: VS Code Live Server
1. Open the `New-portfolio` folder in Visual Studio Code.
2. Install the **Live Server** extension (`ritwickdey.LiveServer`).
3. Click **"Go Live"** in the bottom status bar or right-click `index.html` ➔ **"Open with Live Server"**.

### Option 3: Direct File Execution
You can directly open `index.html` in Google Chrome, Microsoft Edge, Firefox, or Safari.

## 🚢 Deployment Guide

### Deploying to GitHub Pages
1. Push this repository to GitHub:
   ```bash
   git add .
   git commit -m "feat: portfolio updates"
   git push origin main
   ```
2. Go to **Settings ➔ Pages** on your GitHub repository.
3. Under **Branch**, select `main` and `/ (root)`.
4. Click **Save**. Your site will be live at `https://bittush8789.github.io/ai-forward-deployed-engineer-portfolio/`.

### Deploying to Vercel
```bash
npx vercel
```

### Deploying to Netlify
Drag and drop the `New-portfolio` root directory directly into [Netlify Drop](https://app.netlify.com/drop).

## 🎨 Theme Customization

Colors, fonts, and radii are managed via CSS custom properties in `css/style.css`:

```css
:root {
  --primary: #2563eb;       /* Electric Blue */
  --secondary: #7c3aed;     /* Royal Violet */
  --accent-cyan: #06b6d4;   /* Cyan Glow */
  --font-main: 'Plus Jakarta Sans', sans-serif;
  --font-mono: 'JetBrains Mono', monospace;
}
```

Dark mode variables are configured under `[data-bs-theme="dark"]` to ensure high contrast, accessibility, and vibrant glowing states.
